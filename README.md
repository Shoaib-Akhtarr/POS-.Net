# 🛒 POS-.Net: Modern Point of Sale System

![POS Header](header.png)

A comprehensive, high-performance Point of Sale (POS) system built with **C#**, **WPF**, and **Entity Framework Core**. This application provides a streamlined experience for managing sales, inventory, and customer relations with a focus on speed and reliability.

---

## ✨ Key Features

- 📱 **Dynamic POS Interface**: Fast and intuitive sales screen for item lookup and checkout.
- 📦 **Inventory Management**: Comprehensive tracking of products, stock levels, and purchases.
- 👥 **Customer Ledger**: Manage customer accounts, track credit/balances, and view transaction history.
- 📄 **Thermal Printing**: Built-in support for thermal receipt printers with customizable layouts.
- 📊 **Insightful Reporting**: Generate detailed records for sales and purchases.
- 🛡️ **Data Security**: Automated backup and recovery system to ensure your business data is always safe.
- ⌨️ **Keyboard Shortcuts**: Optimized for efficiency with configurable shortcuts for power users.

---

## 🛠️ Tech Stack

- **Lanuage**: C#
- **Framework**: .NET / WPF (Windows Presentation Foundation)
- **Database**: SQLite with Entity Framework Core
- **Architecture**: MVVM (Model-View-ViewModel)

---

## 🚀 Getting Started

### Prerequisites
- Visual Studio 2022
- .NET SDK (Compatible with the project version)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Shoaib-Akhtarr/POS-.Net.git
   ```
2. Open `POS.slnx` in Visual Studio.
3. Restore NuGet packages.
4. Build and Run the project.
